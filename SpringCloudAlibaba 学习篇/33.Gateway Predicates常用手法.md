# 33.Gateway Predicates常用手法
## After | Before | Between
### 功能
在指定时间前、之间、后才启用
### 使用
10:14之前请求将被转发到service1,10:14之后请求将被转发到service2
```
    gateway:
      routes:
        - id: "service1"
          uri: lb://gateway-service1
          predicates:
            - Before=2023-06-18T10:14+08:00[Asia/Shanghai]
          filters:
            - StripPrefix=1
        - id: "service2"
          uri: lb://gateway-service2
          predicates:
            - After=2023-06-18T10:14+08:00[Asia/Shanghai]
          filters:
            - StripPrefix=1
```
## Cookie
### 功能
匹配cookie中指定的key和value才启用
### 使用
cookie中name=ams 请求service2,name=example 请求service1
```
    gateway:
      routes:
        - id: "service1"
          uri: lb://gateway-service1
          predicates:
            - Cookie=name,example
          filters:
            - StripPrefix=1
        - id: "service2"
          uri: lb://gateway-service2
          predicates:
            - Cookie=name,ams
          filters:
            - StripPrefix=1
```

## Method
### 功能
Method等于指定类型则启用
### 使用
Header中name=ams 请求service2,name=example 请求service1
```
    gateway:
      routes:
        - id: "service1"
          uri: lb://gateway-service1
          predicates:
            - Method=GET
          filters:
            - StripPrefix=1
        - id: "service2"
          uri: lb://gateway-service2
          predicates:
            - Method=POST,PUT
          filters:
            - StripPrefix=1
```

## Path
### 功能
根据路径匹配，默认演示的就是这种方式，这里介绍另外一个用法
Map<String, String> uriVariables = ServerWebExchangeUtils.getUriTemplateVariables(exchange);

String segment = uriVariables.get("segment");
### 使用
```
    gateway:
      routes:
        - id: "service1"
          uri: lb://gateway-service1
          predicates:
            - Path=/service1/{segment}
          filters:
            - StripPrefix=1
        - id: "service2"
          uri: lb://gateway-service2
          predicates:
            - Path=/service2/{segment}
          filters:
            - StripPrefix=1
```

# 2.Spring Cloud Alibaba和Spring Cloud 之间的关系和区别

## Spring Cloud
Spring Cloud是一个开源的微服务框架，它构建在Spring Framework之上，旨在简化构建和管理分布式系统中的微服务架构。Spring Cloud提供了一系列的组件和工具，以帮助开发人员实现常见的微服务模式和功能，包括服务注册与发现、负载均衡、服务熔断、配置管理、消息总线等。Spring Cloud通过集成其他云原生技术和开源项目，如Netflix OSS、RabbitMQ、Kafka等，提供了丰富的功能和选项。
## Spring Cloud Alibaba
Spring Cloud Alibaba是基于Spring Cloud的一个衍生版本，由阿里巴巴集团开发和维护。它构建在Spring Cloud之上，旨在为基于Spring Cloud的微服务架构提供阿里巴巴的技术栈和中间件的支持。Spring Cloud Alibaba集成了阿里巴巴的Nacos、Sentinel、Dubbo和RocketMQ等组件，为分布式系统提供了一系列功能。它通过这些组件提供了分布式配置、服务注册与发现、服务熔断与限流、消息队列等关键功能，以满足微服务架构中的需求。

## 关系
Spring Cloud和Spring Cloud Alibaba的关系是扩展关系。Spring Cloud Alibaba在Spring Cloud的基础上进行了扩展和增强，提供了更多与阿里巴巴技术栈集成的选项。通过使用Spring Cloud Alibaba，开发人员可以利用阿里巴巴的中间件和工具来构建更完整和综合的微服务架构。同时，Spring Cloud Alibaba仍然兼容和使用Spring Cloud的核心组件，因此可以继续使用Spring Cloud的特性和功能。
## 组件对比
| 功能           | Spring Cloud                      | Spring Cloud Alibaba          |
|----------------|-----------------------------------|-------------------------------|
| 网关           | Spring Cloud Netflix Zuul/Gateway |                               |
| 服务注册与发现 | Spring Cloud Netflix Eureka       | Spring Cloud Alibaba Nacos    |
| 配置中心       | Spring Cloud Config               | Spring Cloud Alibaba Nacos    |
| 服务限流       | Spring Cloud Netflix Hystrix      | Spring Cloud Alibaba Sentinel |
| 服务熔断       | Spring Cloud Netflix Hystrix      | Spring Cloud Alibaba Sentinel |
| 分布式事务     | TX-LCN                            | Spring Cloud Alibaba Seata    |
| 服务调用       | feign/OpenFeign                   |                               |

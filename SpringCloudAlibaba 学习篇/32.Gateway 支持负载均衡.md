# 32.Gateway 支持负载均衡
在第一节中，我们演示的是转发到指定的一个服务实例，但是在生产环境我们肯定不会这样配置的，我们需要结合nacos注册中心和负载均衡，找到其中一个服务实例，那么这节课就给大家演示gateway如何使用负载均衡来请求目标服务，

## 注册服务
将上节课我们创建的两个服务注册到nacos中
```
    implementation 'org.springframework.boot:spring-boot-starter-web'
    implementation 'com.alibaba.cloud:spring-cloud-starter-alibaba-nacos-discovery'
```
```
spring:
  application:
    name: gateway-service1/gateway-service2
  cloud:
    nacos:
      discovery:
        #        ephemeral: false
        server-addr: 192.168.64.2:8848
        namingRequestTimeout: 10000000
```
## 网关改动
### 加入nacos 和负载均衡的依赖
```
implementation 'com.alibaba.cloud:spring-cloud-starter-alibaba-nacos-discovery'
implementation 'org.springframework.cloud:spring-cloud-starter-loadbalancer'
```
### 修改配置
lb 代表使用负载均衡
```
spring:
  application:
    name: gateway-server
  cloud:
    nacos:
      discovery:
        #        ephemeral: false
        server-addr: 192.168.64.2:8848
        namingRequestTimeout: 10000000
    gateway:
      routes:
        - id: "service1"
          uri: lb://gateway-service1
          predicates:
            - Path=/service1/**
          filters:
            - StripPrefix=1
        - id: "service2"
          uri: lb://gateway-service2
          predicates:
            - Path=/service2/**
          filters:
            - StripPrefix=1
```

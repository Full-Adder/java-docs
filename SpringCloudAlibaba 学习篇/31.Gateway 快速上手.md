# 31.Gateway 快速上手
## Gateway能做什么  
### 路由功能
Spring Cloud Gateway可以根据配置将请求路由到不同的微服务实例或URL上。它支持动态路由，可以根据请求的路径、HTTP方法、请求头等条件进行路由。

### 过滤器功能
Gateway提供了一系列的过滤器，可以在请求被路由前或之后对请求和响应进行修改和处理。过滤器可以用于认证、鉴权、请求限流、请求转发等操作。

### 断路器功能
Gateway集成了断路器模式，可以在微服务出现故障或超时时进行熔断，防止故障扩散到整个系统。

### 负载均衡功能
Gateway支持多种负载均衡算法，可以根据配置将请求分发到不同的微服务实例上，实现负载均衡。

### 支持动态刷新
Gateway可以通过配置中心实现动态刷新路由和过滤器的配置，不需要重启服务即可生效。

### 创建Gateway Server
#### 引入依赖
不再需要引入springboot-web了
```
dependencies {
    implementation 'org.springframework.cloud:spring-cloud-starter-gateway'
}
```
#### 编写路由配置
在applicaion.yaml中配置
```
spring:
  cloud:
    gateway:
      routes:
        - id: "service1"
          uri: "http://localhost:8081/serviceInfo"
          predicates:
            - Path=/service1/**
          filters:
            - StripPrefix=1
        - id: "service2"
          uri: "http://localhost:8082/serviceInfo"
          predicates:
            - Path=/service2/**
          filters:
            - StripPrefix=1
```

### 参数解释
* id：自定义路由ID,保持唯一即可
* uri: 支持普通url及负载均衡服务
* predicates: 根据匹配规则，判断是否执行此路由
* filters:过滤规则，包含pre和post,这里的stripprefix=1代表擦出service2和service1部分，剩下的全部转到目标服务

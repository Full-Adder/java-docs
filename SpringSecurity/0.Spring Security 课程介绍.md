# 0.Spring Security 课程介绍
## 学习前的痛点
* 原理不清晰
* 配置复杂
* 缺乏实战经验
* 想自定义配置却不知道从哪下手
## 课程适用人群
* 想入门Spring Security
* 需要进阶学习Spring Security
* 想学习Spring Security 原理
* 想自定义Spring Security 配置
* 无法解决Spring Security 产生的问题
## 课程特色：
* 从零开始讲解基本概念
* 由浅入深讲解基本原理
* 围绕实战项目进行案例分析
* 讲解目前项目中最常用的技术点

## 课程目标
务必让所有同学都能看懂听懂，最终可以根据自己项目中的需求对SpringSecurity进行定制。
## 项目环境
SpringBoot : 2.7.10
SpringSecurity: 5.7.7
自动化构建工具:Gradle
JDK: 17

# 2.正则表达式语法
正则表达式（正则）的语法由一系列字符和操作符组成，用于定义字符串的模式。以下是一些常见的正则表达式语法元素：

## 字面字符
普通字符： 大多数字符表示它们自身。例如，字母和数字大多直接匹配自身。

## 元字符
* .（点）： 匹配除换行符之外的任意字符。

```
a.b   // 匹配 "aab"、"axb"、"a@b" 等
```

* ^： 匹配字符串的开头。

```
^abc  // 匹配以 "abc" 开头的字符串
```
* $： 匹配字符串的结尾。
```
xyz$  // 匹配以 "xyz" 结尾的字符串
```
* \d \D 匹配一个数字或非数字
* \n 匹配换行符
* \s \S 匹配空白字符 或 非空白字符
* \w \W 匹配任何单词 或 非单词 [A-Za-z0-9_]
## 字符类
* [...]： 匹配方括号内的任何字符。
```
[aeiou]  // 匹配任何一个元音字母
```
* [^...]： 在字符类内，^ 表示取反，匹配不在方括号内的任何字符。
```
[^0-9]   // 匹配任何非数字字符
```
## 量词
* *： 匹配零次或多次前面的元素。

```
a*   // 匹配 "a"、"aa"、"aaa" 等
```
* +： 匹配一次或多次前面的元素。
```
b+   // 匹配 "b"、"bb"、"bbb" 等
```
* ?： 匹配零次或一次前面的元素。
```
c?   // 匹配 "c" 或空字符串
```
* {n}： 匹配恰好 n 次前面的元素。
```
d{3}   // 匹配 "ddd"
```
* {n,}： 匹配至少 n 次前面的元素。
```
e{2,}   // 匹配 "ee"、"eee"、"eeee" 等
```
* {n,m}： 匹配至少 n 次且不超过 m 次前面的元素。

```
f{2,4}   // 匹配 "ff"、"fff"、"ffff"
```

这些元素只是正则表达式语法的一部分，正则表达式还有许多高级特性和选项，具体取决于支持正则表达式的工具或语言。学习正则表达式通常需要不断练习和实践，逐渐掌握其强大的文本匹配和处理能力。

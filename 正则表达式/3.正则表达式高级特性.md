# 3.正则表达式高级特性
## 转义字符
* \： 转义字符，用于匹配元字符本身。
```
\.   // 匹配句点字符 "."
\?  // 匹配?
\+ // 匹配+
\*  // 匹配*
```
## 分组和捕获
(...)： 创建一个分组，可以对其应用量词。

```
(abc)+   // 匹配 "abc"、"abcabc" 等 group(1) 可以获取
```
* (?:...)： 非捕获分组，不捕获匹配的内容。
```
(?:ab)+   // 匹配 "ab"、"abab" 等，group(1) 获取不到
```
## 零宽断言
* (?=...)： 正向肯定预查，匹配在某些内容之前的位置。

```
a(?=b)   // 匹配 "a"，但仅当其后面跟着 "b"
```
* (?!...)： 正向否定预查，匹配不在某些内容之前的位置。
```
x(?!y)   // 匹配 "x"，但仅当其后面不跟着 "y"
```
* (?<=...)： 反向肯定预查，匹配在某些内容之后的位置。
```
(?<=a)b   // 匹配 "b"，但仅当其前面是 "a"
```
* (?<!...)： 反向否定预查，匹配不在某些内容之后的位置。

```
(?<!x)y   // 匹配 "y"，但仅当其前面不是 "x"
```

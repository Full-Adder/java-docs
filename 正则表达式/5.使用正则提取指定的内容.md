# 5.使用正则提取指定的内容
## group() 和 group(n)的区别
在正则表达式中，group() 方法用于获取匹配到的子组。

group(0) 返回整个匹配结果。
group(1) 返回第一个括号内匹配到的内容。
group(2) 返回第二个括号内匹配到的内容。
...以此类推。
例如，对于正则表达式 ^(d{3})-(\d{2})-(\d{4})$，它匹配一个由三个数字、一个短横线、两个数字和一个短横线组成的字符串。如果使用 group() 方法，可以分别获取这三个数字和两个短横线：
```
public void testMatchGroup() {
        String input = "123-45-6789-987-34-2632";
        String regex = "(\\d{3})-(\\d{2})-(\\d{4})";

        Pattern pattern = Pattern.compile(regex);
        Matcher matcher = pattern.matcher(input);

        while (matcher.find()) {
            System.out.println("整个匹配结果： " + matcher.group());
            System.out.println("第一个分组： " + matcher.group(1));
            System.out.println("第二个分组： " + matcher.group(2));
            System.out.println("第三个分组： " + matcher.group(3));
        }
    }
```

## 提取数字：
```
public void testNum() {
        String text = "这里有一些数字：12, 34, 56, 78";
        Pattern pattern = Pattern.compile("\\d+");
        Matcher matcher = pattern.matcher(text);
        while (matcher.find()) {
            System.out.println(matcher.group());
        }
    }
```

## 提取中文字符：
```
基本汉字20902字：4E00-9FA5
基本汉字补充90字：9FA6-9FFF
扩展A    6592字：3400-4DBF
全角ASCII、中英文标点：FF00-FFEF
CJK部首补充：2E80-2EFF
CJK标点符号：3000-303F
CJK笔划：31C0-31EF
```
```
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class Main {
    public static void main(String[] args) {
        String text = "这是一段包含中文的文本：你好，世界！";
        Pattern pattern = Pattern.compile("[\u4e00-\u9fa5]+");
        Matcher matcher = pattern.matcher(text);
        while (matcher.find()) {
            System.out.println(matcher.group());
        }
    }
}
```

    public void testHtmlTag() {

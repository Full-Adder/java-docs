# 1. 快速上手
## LangChain4j 介绍

LangChain4j 是一个专为 Java 生态系统设计的开源框架，旨在简化大语言模型（LLMs）与各类应用程序的集成过程。它借鉴了 Python 生态中 LangChain 的核心思想，但针对 Java 开发者的使用习惯和技术栈进行了优化，提供了更贴合 Java 生态的 API 和工具链。


### 核心定位与目标

LangChain4j 的核心目标是降低大语言模型应用开发的门槛，帮助开发者更高效地构建基于 LLMs 的智能应用。无论是简单的对话机器人、复杂的知识问答系统，还是需要结合外部数据的决策支持工具，LangChain4j 都能提供模块化的组件和清晰的流程设计，减少重复开发工作。


### 主要功能与组件

LangChain4j 围绕“链（Chain）”和“代理（Agent）”两大核心概念设计，提供了丰富的组件库，主要包括：

#### 1. 模型集成（Models）
- 支持主流大语言模型：可与 OpenAI（GPT 系列）、Anthropic（Claude）、Google（Gemini）、本地模型（如 Llama 系列、Qwen 等）等无缝对接，统一调用接口，降低切换模型的成本。
- 模型配置灵活：支持设置温度（temperature）、最大 tokens、超时时间等参数，满足不同场景的精度和性能需求。

#### 2. 提示工程（Prompt Engineering）
- 提示模板（Prompt Templates）：允许开发者定义可复用的提示模板，动态填充变量，避免硬编码。
- 提示优化：提供工具辅助调整提示词，提升模型响应质量。

#### 3. 链（Chains）
- 基础链：将多个操作（如模型调用、数据处理）按顺序串联，形成流水线式的工作流程。
- 复杂链：支持条件分支、循环等逻辑，可构建更灵活的业务流程（如“先检索知识库，再生成回答”的检索增强生成（RAG）链）。

#### 4. 检索增强生成（RAG）
- 与向量数据库集成：支持 Pinecone、Milvus、Weaviate 等主流向量库，实现外部知识的高效检索。
- 文档处理：提供文档加载、分割、嵌入（Embedding）等工具，简化知识库构建流程。

#### 5. 代理（Agents）
- 赋予模型决策能力：允许模型根据任务需求，自主选择调用工具（如计算器、搜索引擎、数据库查询），逐步解决复杂问题。
- 工具集成：支持自定义工具，扩展模型的能力边界。

#### 6. 记忆（Memory）
- 对话记忆：保存对话历史，使模型能基于上下文生成连贯的响应，支持短期记忆、长期记忆等多种模式。


### 优势特点

- **Java 原生支持**：完全基于 Java 开发，无缝集成 Spring Boot 等主流 Java 框架，符合 Java 开发者的编码习惯。
- **轻量级设计**：核心依赖少，易于上手和部署，可灵活适配不同规模的项目。
- **模块化与可扩展性**：各组件解耦，支持自定义实现（如自定义模型适配器、工具等），便于扩展。
- **丰富的生态集成**：与 Java 生态中的常用库（如 Jackson、SLF4J）和外部服务（如数据库、云服务）兼容性良好。


我们无需提前注册大模型的key，可以直接使用langchain为我们提供的demo key用来调用 Opena AI

### 集成Open AI
编写配置文件application.properties
```
langchain4j.open-ai.chat-model.api-key=demo
langchain4j.open-ai.chat-model.base-url=http://langchain4j.dev/demo/openai/v1
langchain4j.open-ai.chat-model.model-name=gpt-4o-mini
```
 我们可以使用两种方式创建chatmodel
 手动构建
```
    @Test
    public void test() {
        OpenAiChatModel model = OpenAiChatModel.builder()
                .baseUrl("http://langchain4j.dev/demo/openai/v1")
                .apiKey("demo")
                .modelName("gpt-4o-mini")
                .build();
        String message = model.chat("你好啊");
        System.out.println(message);
    }
 
```
自动注入
```
    @Autowired
    private OpenAiChatModel model;
    
    @Test
    public void testOpenAI() {
        String message = model.chat("请你做下自我介绍");
        System.out.println(message);
    }
```
 调用其他大模型，需要提前在平台上创建好对应的key
 
 ### 集成千问大模型
 引入千问模型
 ```
langchain4j.community.dashscope.chat-model.api-key=${key}
langchain4j.community.dashscope.chat-model.model-name=qwen-plus
```
### 集成智普大模型
引入智普大模型
```
langchain4j.open-ai.chat-model.api-key=${key}
langchain4j.open-ai.chat-model.base-url=https://open.bigmodel.cn/api/paas/v4/
langchain4j.open-ai.chat-model.model-name=glm-4-plus
```

### 集成deepseek大模型
引入deepseek
```
langchain4j.open-ai.chat-model.api-key=${key}
langchain4j.open-ai.chat-model.base-url=https://api.deepseek.com
langchain4j.open-ai.chat-model.model-name=deepseek-chat
```

### 集成ollama
引入ollama
```

@Autowired
private OllamaChatModel ollamaChatModel;


langchain4j.ollama.chat-model.base-url=http://localhost:11434
langchain4j.ollama.chat-model.model-name=llama3.2:latest
```

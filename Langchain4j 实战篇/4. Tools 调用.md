# 4. Tools 调用
## 介绍
LangChain4j 的函数调用是其工具（tools）功能的核心实现方式，允许大语言模型（LLM）在处理任务时，主动调用外部函数或方法（如自定义逻辑、API接口、数据库操作等），从而扩展模型的能力，解决仅靠模型自身无法完成的任务（如实时数据获取、复杂业务逻辑处理等）。


### 核心特点
- **模型自主决策调用**：LLM 会根据用户问题自动判断是否需要调用函数，以及调用哪个函数、传递什么参数，无需人工干预。
- **连接外部能力**：通过函数调用，模型可以对接数据库查询、第三方API（如天气、支付、地图服务）、本地业务系统等，获取实时或定制化数据。
- **结果整合生成回答**：函数执行后返回的结果会被模型接收，模型再结合这些结果生成自然语言回答，形成“提问→调用函数→处理结果→回答”的完整流程。


### 典型流程
1. 用户提出需要外部信息的问题（例如“查询某城市明天的天气并推荐景点”）。
2. LLM 分析问题，判断需要调用“天气查询函数”和“景点推荐函数”。
3. 模型按格式生成函数调用指令（包含函数名、参数，如城市名称）。
4. 框架执行对应函数，获取返回结果（如“晴，25℃”“故宫、颐和园”）。
5. LLM 整合结果，生成自然语言回答（如“明天该城市天气晴朗，推荐前往故宫游玩”）。

## 代码示例
### 没有tools的情况
在不使用tools场景下，如果我们问当前时间,看它是否会返回正确的时间？
```
    @Test
    public void test7() {
        System.out.println(assistantWithMemory.ask("现在几点了？"));
    }
```
```
现在是北京时间2024年6月14日11点54分。不过，请注意这个时间是基于我最后的更新时间，实际当前时间可能会有所不同。你可以查看所在设备的时间或搜索实时时间以获取更准确的信息。
```
很明显他给的结果是不对的，所以我们接下来引入tools

### 集成tools
定义个一个方法用来获取当前时间
```
@Component
public class Tools {
    @Tool
    public String getNowDate() {
        return new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(new Date());
    }
}
```
自定义ai service，注册tools
```
@AiService(wiringMode = EXPLICIT, chatModel = "qwenChatModel", tools = "tools")
public interface AssistantWithTools {
    String ask(String question);
}
```
使用AssistantWithTools 来提问
```
    @Test
    public void test7() {
        System.out.println(assistantWithTools.ask("现在几点了？"));
    }
```
```
现在是2025年7月19日，时间是08:47:01。
```
可以看出在注册了tools之后，他回答了正确的时间

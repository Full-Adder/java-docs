# 2.AI Service 使用
LangChain4j 的 **AI Service** 是其核心功能模块之一，旨在通过简洁的注解式编程，帮助开发者快速将大语言模型（LLMs）能力集成到 Java 应用中，无需手动处理复杂的模型调用、提示词构建或结果解析逻辑。
## 介绍

### 核心特点
- **声明式开发**：通过 `@AiService` 注解标记接口，直接定义抽象方法，LangChain4j 会自动生成实现类，底层对接 LLM 完成调用。
- **简化提示工程**：方法名、参数名和返回值类型会被自动转化为提示词的一部分，开发者无需手动拼接提示文本。
- **支持复杂场景**：可结合对话记忆（Memory）、工具调用（Tools）、检索增强（RAG）等功能，实现带上下文的对话、多步骤任务处理等。


### 基本用法示例
1. 手动builder AI Service
```
  public interface Assistant {

    @SystemMessage("你是李白")
    String ask(String question);
}

  @Test
    public void test(){
        Assistant assistant = AiServices.builder(Assistant.class).chatLanguageModel(qwenChatModel).build();
        System.out.println(assistant.ask("我看到了一个鸡腿，你可写首诗么?"));
    }
   ```
2. 使用AiService 注解，直接注入使用
```
    @AiService(wiringMode = EXPLICIT, chatModel = "qwenChatModel")
public interface AssistantWithAnnot {
    @SystemMessage("你是李白")
    String ask(String question);
}   
    @Test
    public void test1() {
        System.out.println(assistantWithAnnot.ask("我看到了一个🍗"));
    }
```
3. prompt中使用参数
```
@AiService(wiringMode = EXPLICIT, chatModel = "qwenChatModel")
public interface AssistantWithParams{

    @SystemMessage("你是 {{user}}")
    String ask(@UserMessage String question, @V("user") String user);
}

    @Test
    public void test2(){
        System.out.println(assistantWithParams.ask("请介绍一下自己","李白"));
        System.out.println("=====================================");
        System.out.println(assistantWithParams.ask("请介绍一下自己","杜甫"));
        System.out.println("=====================================");
        System.out.println(assistantWithParams.ask("请介绍一下自己","苏轼"));
        System.out.println("=====================================");
    }
```



### 扩展能力
- **记忆集成**：通过 `@MemoryId` 标记参数，让模型记住对话历史，支持多轮连贯对话。
- **工具调用**：在方法上添加 `@Tool` 注解，允许模型根据需求自动调用外部工具（如计算器、数据库查询）。
- **结果定制**：支持返回自定义对象（LangChain4j 会自动解析 LLM 输出为对象），无需手动处理 JSON 或文本解析。

简言之，AI Service 是 LangChain4j 为 Java 开发者提供的“零样板代码”集成方案，大幅降低了 LLM 应用的开发门槛。

# 9.实现多租户

## 背景
如果你的项目服务于多家企业，那你肯定会使用到多租户，实现数据隔离。这里说的不是数据权限的隔离，而是真正意义上的数据隔离，为每个租户维护自己的一套数据，租户之间是相互不可见的。为了实现这一目的，普遍采用的方案是在每张表中新增一个字段，然后每次处理数据的时候都去手动维护这个字段，这个基本就解决了在同一个数据表中实现的租户方式。
那么在这里，MyBatisPlus也并没有给我们提供另外一种方式去实现租户，而是帮我们去做了手动维护租户字段的步骤，我们写sql的时候完全可以当租户这个字段是透明的，因为MyBtisPlus已经帮我们维护好了。

## 引入配置
```
package com.example.mybatispluslearning.configuration;

import com.baomidou.mybatisplus.annotation.DbType;
import com.baomidou.mybatisplus.extension.plugins.MybatisPlusInterceptor;
import com.baomidou.mybatisplus.extension.plugins.handler.TenantLineHandler;
import com.baomidou.mybatisplus.extension.plugins.inner.PaginationInnerInterceptor;
import com.baomidou.mybatisplus.extension.plugins.inner.TenantLineInnerInterceptor;
import net.sf.jsqlparser.expression.Expression;
import net.sf.jsqlparser.expression.LongValue;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import java.util.Arrays;
import java.util.List;

@Configuration
public class MybatisPlusConfig {
    private List<String> needHandleTenantTables = Arrays.asList("test_tenant");
    /**
     * 分页插件，自动识别数据库类型
     */
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new TenantLineInnerInterceptor(new TenantLineHandler() {
            @Override
            public Expression getTenantId() {
                return new LongValue(1);
            }

            // 这是 default 方法,默认返回 false 表示所有表都需要拼多租户条件
            @Override
            public boolean ignoreTable(String tableName) {
                return !needHandleTenantTables.contains(tableName);
            }
        }));
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }

}
```
## 表中维护租户字段
```
CREATE TABLE `test_tenant` (
  `id` int DEFAULT NULL,
  `name` varchar(255) DEFAULT NULL,
  `teacher` varchar(255) DEFAULT NULL,
  `student` varchar(255) DEFAULT NULL,
  `tenant_id` int DEFAULT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

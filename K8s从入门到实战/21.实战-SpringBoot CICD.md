# 21.实战-SpringBoot CICD
## 安装gitLab
```
步骤如下：
安装配置依赖项
sudo apt-get update
sudo apt-get install -y curl openssh-server ca-certificates

安装发送邮件的（可以用自己熟悉的代替）
sudo apt-get install -y postfix

安装过程中会弹出对话框，按TAB键让按钮点亮后按Enter或者空格。填文字的地方随便写，是邮件中显示的发送者。
下载安装脚本
curl https://packages.gitlab.com/install/repositories/gitlab/gitlab-ce/script.deb.sh | sudo bash

修改安装脚本
vim /etc/apt/sources.list.d/gitlab_gitlab-ce.list

把原来的两行删除或者注释（#是行注释），然后增加
deb https://mirrors.tuna.tsinghua.edu.cn/gitlab-ce/ubuntu bionic main
deb-src https://mirrors.tuna.tsinghua.edu.cn/gitlab-ce/ubuntu bionic main

apt-key adv --keyserver keyserver.ubuntu.com --recv-keys 3F01618A51312F3F
再次执行
sudo apt-get update

执行安装脚本
sudo EXTERNAL_URL="http://192.168.2.99" apt-get install gitlab-ce

这里注意，没有域名就直接使用ip，如果想要修改IP这里是需要修改配置文件的
sudo vim /etc/gitlab/gitlab.rb 

然后修改里面的
external_url 'http://192.168.183.128:8090'
```
最终出现这个页面代表安装成功，现在执行命令获取密码
![](media/17088287574365/17101938512078.jpg)
```
cat /etc/gitlab/initial_root_password
```
![](media/17088287574365/17101940024315.jpg)
登陆成功之后，第一件事就是修改密码
![](media/17088287574365/17101940423960.jpg)
到此gitLab安装成功

#### build and push
*   修改mvn指令： 
```
mvn -Dmaven.test.skip=true clean package
```
* 修改build指令
```
docker build -t $REGISTRY/$PROJECT_ID/$APP_NAME:$BUILD_NUM .
```
* 创建docker镜像仓库凭证
    ![](media/17088287574365/17106409262827.jpg)
    ![](media/17088287574365/17106409764581.jpg)
    ![](media/17088287574365/17106409870115.jpg)
* 修改docker push脚本
    ```
    docker push $REGISTRY/$PROJECT_ID/$APP_NAME:$BUILD_NUM
    ```
#### Push Latest
* 修改条件分支：main
![](media/17088287574365/17106444998212.jpg)

* 修改tag脚本
```
docker tag  $REGISTRY/$PROJECT_ID/$APP_NAME:$BUILD_NUM $REGISTRY/$PROJECT_ID/$APP_NAME:latest
```    
* 修改Push 脚本
```
docker push $REGISTRY/$PROJECT_ID/$APP_NAME:latest 
```
#### Deploy to dev
* 删除审核，测试不需要这个
* 创建kube凭证

![](media/17088287574365/17106416340384.jpg)
![](media/17088287574365/17106416549313.jpg)
![](media/17088287574365/17106416635511.jpg)

* 修改deploy指令
```
envsubst < deployment-dev.yaml | kubectl apply -f -
```
* 删除deploy to production

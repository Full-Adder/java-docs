# 5.自动化映射枚举
MyBatis-Plus 提供了强大的枚举自动映射功能，可以优雅地处理数据库字段与Java枚举类型之间的转换。以下是完整的实现方案：

## 一、基础实现方式

### 1. 使用 `@EnumValue` 注解（推荐）

```java
public enum GenderEnum {
    MALE("M", "男性"),
    FEMALE("F", "女性");
    
    @EnumValue // 标记要存储到数据库的值
    private final String code;
    private final String desc;
    
    GenderEnum(String code, String desc) {
        this.code = code;
        this.desc = desc;
    }
}
```

### 2. 实现 `IEnum` 接口

```java
public enum StatusEnum implements IEnum<Integer> {
    LOCK(1, "lock"), 
    DISABLE(2, "disable");
    
    private final int value;
    private final String desc;
    
    StatusEnum(int value, String desc) {
        this.value = value;
        this.desc = desc;
    }
    
    @Override
    public Integer getValue() {
        return this.value;
    }
}
```

## 二、配置扫描枚举(3.5.2之前)

在 `application.yml` 中配置枚举包路径：

```yaml
mybatis-plus:
  type-enums-package: com.example.enums # 枚举类所在包
```

## 三、实体类中使用枚举

```java
@Data
public class User {
    private StatusEnum status;     // 使用IEnum实现的枚举
    private GenderEnum gender; // 使用@EnumValue注解的枚举
}
```

## 四、数据库表设计示例

```sql
CREATE TABLE user (
    id BIGINT PRIMARY KEY,
    name VARCHAR(50),
    status INT,      -- 对应AgeEnum的value
    gender CHAR(1) -- 对应GenderEnum的code
);
```

## 五、常见问题解决方案

### 1. 枚举值为null的问题

**原因**：数据库字段类型与枚举值类型不匹配（如tinyint映射到boolean）

**解决方案**：
• 修改数据库字段类型为int/varchar
• 或调整枚举值定义匹配数据库类型

### 2. JSON序列化问题

使用Jackson时添加注解：

```java
public enum GenderEnum {
    @JsonValue // 指定序列化时使用的值
    MALE("M", "男性"),
    FEMALE("F", "女性");
    // ...
}
```

## 六、版本差异说明

• **3.5.2+**：只需声明枚举属性即可自动映射，无需额外配置
• **3.5.2之前**：需要显式配置`typeEnumsPackage`

## 最佳实践建议

1. 优先使用`@EnumValue`注解方式，更灵活
2. 保持数据库字段类型与枚举值类型一致
3. 为枚举添加描述字段便于前端展示

通过以上配置，MyBatis-Plus可以实现数据库字段与枚举类型的自动转换，大大简化了开发工作。

# 3.条件构造器 使用示例

MyBatis-Plus 的条件构造器(Wrapper)是构建动态SQL查询条件的强大工具，提供了类型安全且简洁的API。以下是完整的条件构造器使用实例，包括传统方式和Lambda方式。

## 一、条件构造器类型

MyBatis-Plus 提供了多种条件构造器：

1. **QueryWrapper**：通用查询条件构造器
2. **UpdateWrapper**：更新操作条件构造器
3. **LambdaQueryWrapper**：Lambda语法查询构造器
4. **LambdaUpdateWrapper**：Lambda语法更新构造器

## 二、基础查询条件示例

### 1. 等值查询

```java
// 传统方式
QueryWrapper<User> queryWrapper = new QueryWrapper<>();
queryWrapper.eq("name", "张三")
           .ne("age", 18); // 不等于

// Lambda方式
LambdaQueryWrapper<User> lambdaWrapper = new LambdaQueryWrapper<>();
lambdaWrapper.eq(User::getName, "张三")
             .ne(User::getAge, 18);
```

### 2. 范围查询

```java
// 传统方式
queryWrapper.gt("age", 18)  // 大于
           .ge("age", 20)   // 大于等于
           .lt("age", 30)   // 小于
           .le("age", 25)   // 小于等于
           .between("age", 20, 30); // 区间

// Lambda方式
lambdaWrapper.gt(User::getAge, 18)
             .ge(User::getAge, 20)
             .lt(User::getAge, 30)
             .le(User::getAge, 25)
             .between(User::getAge, 20, 30);
```

### 3. 模糊查询

```java
// 传统方式
queryWrapper.like("name", "张")    // %张%
           .likeLeft("name", "张") // %张
           .likeRight("name", "张")// 张%
           .notLike("name", "李"); // 不包含

// Lambda方式
lambdaWrapper.like(User::getName, "张")
             .likeLeft(User::getName, "张")
             .likeRight(User::getName, "张")
             .notLike(User::getName, "李");
```

## 三、复杂条件组合

### 1. AND/OR条件组合

```java
// 传统方式
queryWrapper.and(w -> w.eq("name", "张三").or().eq("name", "李四"))
           .or(w -> w.gt("age", 20).lt("age", 30));

// Lambda方式
lambdaWrapper.and(w -> w.eq(User::getName, "张三").or().eq(User::getName, "李四"))
             .or(w -> w.gt(User::getAge, 20).lt(User::getAge, 30));
```

### 2. 嵌套条件

```java
// 传统方式
queryWrapper.nested(w -> w.eq("name", "张三").or().eq("name", "李四"))
           .and(w -> w.gt("age", 20).lt("age", 30));

// Lambda方式
lambdaWrapper.nested(w -> w.eq(User::getName, "张三").or().eq(User::getName, "李四"))
             .and(w -> w.gt(User::getAge, 20).lt(User::getAge, 30));
```

## 四、排序与分页

### 1. 排序

```java
// 传统方式
queryWrapper.orderByAsc("age", "id")  // 升序
           .orderByDesc("create_time"); // 降序

// Lambda方式
lambdaWrapper.orderByAsc(User::getAge, User::getId)
             .orderByDesc(User::getCreateTime);
```

### 2. 分页

```java
// 配置分页插件后使用
Page<User> page = new Page<>(1, 10); // 当前页，每页大小
LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
wrapper.gt(User::getAge, 20);
Page<User> result = userMapper.selectPage(page, wrapper);
```

## 五、字段选择

```java
// 传统方式
queryWrapper.select("id", "name", "age");

// Lambda方式
lambdaWrapper.select(User::getId, User::getName, User::getAge);
```


## 六、更新操作条件构造器

### 1. UpdateWrapper

```java
UpdateWrapper<User> updateWrapper = new UpdateWrapper<>();
updateWrapper.set("age", 30)
             .set("email", "new@example.com")
             .eq("name", "张三");

userMapper.update(null, updateWrapper);
```

### 2. LambdaUpdateWrapper

```java
LambdaUpdateWrapper<User> lambdaUpdate = new LambdaUpdateWrapper<>();
lambdaUpdate.set(User::getAge, 30)
            .set(User::getEmail, "new@example.com")
            .eq(User::getName, "张三");

userMapper.update(null, lambdaUpdate);
```

## 七、动态条件构建

```java
String name = "张三";
Integer minAge = 20;
Integer maxAge = 30;

LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
wrapper.eq(StringUtils.isNotBlank(name), User::getName, name)
      .gt(minAge != null, User::getAge, minAge)
      .lt(maxAge != null, User::getAge, maxAge);
```

## 八、子查询

```java
// 传统方式
queryWrapper.inSql("id", "select id from user where age > 20");

// Lambda方式
lambdaWrapper.inSql(User::getId, "select id from user where age > 20");

// 更安全的子查询方式
LambdaQueryWrapper<User> subWrapper = new LambdaQueryWrapper<>();
subWrapper.select(User::getId).gt(User::getAge, 20);
lambdaWrapper.in(User::getId, userMapper.selectObjs(subWrapper));
```

## 九、最佳实践

1. **优先使用Lambda方式**：类型安全，重构友好
2. **合理使用动态条件**：避免构建过于复杂的条件
3. **注意SQL注入风险**：避免直接拼接用户输入
4. **批量操作优化**：对于大批量数据，使用分批处理

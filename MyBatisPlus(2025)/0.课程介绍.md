### **💡 章节核心代码示例**  
**3. 条件构造器（避免字段硬编码）**  
```java  
// 传统方式（字段名易错）
QueryWrapper<User> wrapper = new QueryWrapper<>();
wrapper.eq("name", "张三").gt("age", 20); 

// 进阶方式（Lambda防误写）
LambdaQueryWrapper<User> lambdaWrapper = Wrappers.lambdaQuery();
lambdaWrapper.eq(User::getName, "张三").gt(User::getAge, 20); 
```

**7. 雪花ID主键策略**  
```java  
@Data  
public class User {  
    @TableId(type = IdType.ASSIGN_ID) // 雪花算法  
    private Long id;  
}  
```

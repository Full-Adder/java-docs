# 2.IService 使用示例

MyBatis-Plus 的 IService 接口提供了比 BaseMapper 更丰富的 CRUD 操作方法，特别适合在 Service 层使用。以下是 IService 接口的完整案例演示：

## 一、基础配置

### 1. 创建 Service 接口

```java
public interface UserService extends IService<User> {
    // 可以在此添加自定义方法
    List<User> selectByAgeRange(Integer minAge, Integer maxAge);
}
```

### 2. 创建 Service 实现类

```java
@Service
public class UserServiceImpl extends ServiceImpl<UserMapper, User> implements UserService {
    
    @Override
    public List<User> selectByAgeRange(Integer minAge, Integer maxAge) {
        LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
        wrapper.between(User::getAge, minAge, maxAge);
        return this.list(wrapper);
    }
}
```

## 二、IService 核心方法演示

### 1. 保存操作

```java
// 测试保存单个实体
@Test
void testSave() {
    User user = new User();
    user.setName("张三");
    user.setAge(25);
    user.setEmail("zhangsan@example.com");
    boolean result = userService.save(user);
    System.out.println("保存结果：" + result);
}

// 测试批量保存
@Test
void testSaveBatch() {
    List<User> users = new ArrayList<>();
    for (int i = 0; i < 5; i++) {
        User user = new User();
        user.setName("用户" + i);
        user.setAge(20 + i);
        users.add(user);
    }
    boolean result = userService.saveBatch(users);
    System.out.println("批量保存结果：" + result);
}
```

### 2. 保存或更新操作

```java
// 根据ID判断是插入还是更新
@Test
void testSaveOrUpdate() {
    User user = new User();
    user.setId(1L); // 如果ID存在则更新，不存在则插入
    user.setName("更新后的名字");
    boolean result = userService.saveOrUpdate(user);
    System.out.println("保存或更新结果：" + result);
}

// 批量保存或更新
@Test
void testSaveOrUpdateBatch() {
    List<User> users = userService.list();
    users.forEach(user -> user.setName(user.getName() + "_updated"));
    boolean result = userService.saveOrUpdateBatch(users);
    System.out.println("批量保存或更新结果：" + result);
}
```

### 6. 分页查询

```java
// 配置分页插件
@Configuration
public class MybatisPlusConfig {
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor());
        return interceptor;
    }
}

// 分页查询测试
@Test
void testPage() {
    Page<User> page = new Page<>(1, 2); // 当前页，每页大小
    
    // 无条件分页
    Page<User> result1 = userService.page(page);
    System.out.println("总记录数：" + result1.getTotal());
    result1.getRecords().forEach(System.out::println);
    
    // 条件分页
    LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
    wrapper.gt(User::getAge, 20);
    Page<User> result2 = userService.page(page, wrapper);
    System.out.println("年龄大于20的记录数：" + result2.getTotal());
    result2.getRecords().forEach(System.out::println);
}
```

## 三、链式调用示例

MyBatis-Plus 还支持链式调用，使代码更加简洁：

```java
@Test
void testChain() {
    // 查询链式调用
    List<User> users = userService.lambdaQuery()
            .gt(User::getAge, 20)
            .like(User::getName, "张")
            .list();
    users.forEach(System.out::println);
    
    // 更新链式调用
    boolean updateResult = userService.lambdaUpdate()
            .eq(User::getName, "张三")
            .set(User::getAge, 30)
            .update();
    System.out.println("更新结果：" + updateResult);
    
    // 删除链式调用
    boolean removeResult = userService.lambdaUpdate()
            .eq(User::getName, "李四")
            .remove();
    System.out.println("删除结果：" + removeResult);
}
```

## 四、自定义方法实现

在 Service 接口中定义自定义方法并在实现类中实现：

```java
// 在UserService接口中添加方法
List<User> selectByNameAndAge(String name, Integer age);

// 在UserServiceImpl中实现
@Override
public List<User> selectByNameAndAge(String name, Integer age) {
    LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
    wrapper.eq(User::getName, name)
           .gt(User::getAge, age);
    return this.list(wrapper);
}

// 测试自定义方法
@Test
void testCustomMethod() {
    List<User> users = userService.selectByNameAndAge("张三", 20);
    users.forEach(System.out::println);
}
```

## 五、批量操作性能优化

对于大批量数据处理，可以使用分批处理：

```java
@Test
void testBatchPerformance() {
    List<User> users = new ArrayList<>();
    // 假设有10万条数据
    for (int i = 0; i < 100000; i++) {
        User user = new User();
        user.setName("用户_" + i);
        user.setAge(i % 100);
        users.add(user);
    }
    
    // 每1000条执行一次批量插入
    boolean result = userService.saveBatch(users, 1000);
    System.out.println("批量插入结果：" + result);
}
```

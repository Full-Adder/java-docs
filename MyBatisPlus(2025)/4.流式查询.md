# 4.流式查询

### 一、基础流式查询实现

#### 1. 使用`ResultHandler`方式（推荐）
```java
// Mapper接口定义
@Select("SELECT * FROM user ${ew.customSqlSegment}")
@Options(resultSetType = ResultSetType.FORWARD_ONLY)
@ResultType(User.class)
void selectStream(@Param(Constants.WRAPPER) Wrapper<User> wrapper, ResultHandler<User> handler);

// 使用示例
List<User> result = new ArrayList<>();
userMapper.selectStream(Wrappers.emptyWrapper(), context -> {
    User user = context.getResultObject();
    result.add(user);
    System.out.println("已处理第" + context.getResultCount() + "条数据");
});
```

#### 2. 使用`Cursor`方式（Java 8+）

```java
// Mapper接口定义
@Select("SELECT * FROM user LIMIT #{limit}")
Cursor<User> scan(@Param("limit") int limit);

// 使用示例（需保持数据库连接）
try (Cursor<User> cursor = userMapper.scan(100000)) {
    cursor.forEach(user -> {
        // 处理每条数据
    });
}
```
注意：必须手动关闭Cursor或使用try-with-resources 
// 需要在方法上添加 @Transactional

### 二、结合MyBatis-Plus特性的实现

#### 1. 通用BaseMapper流式查询
```java
// 直接使用BaseMapper方法
userMapper.selectList(Wrappers.emptyWrapper(), new ResultHandler<User>() {
    @Override
    public void handleResult(ResultContext<? extends User> context) {
        // 处理数据
    }
});
```
支持所有BaseMapper的查询方法

#### 2. 带条件的分页流式处理
```java
Page<User> page = new Page<>(1, 10000); // 每批1万条
LambdaQueryWrapper<User> wrapper = Wrappers.lambdaQuery();
        wrapper.gt(User::getAge, 20);
userMapper.selectList(page, wrapper, context -> {
    User user = context.getResultObject();
    // 批量处理逻辑
});
```

### 三、不同场景下的选择建议

| 场景 | 推荐方案 | 特点 |
|------|----------|------|
| 简单流式处理 | `ResultHandler` | 配置简单，无需事务管理 |
| Java8流式操作 | `Cursor` | 支持Stream API操作 |
| 大数据量批处理 | 分页+流式 | 内存控制更精确 |
| 复杂事务场景 | `@Transactional` | 保证数据一致性 |

注意事项：
1. 流式查询期间数据库连接会保持打开
2. 避免在流式处理中执行其他数据库操作
3. 合理设置`fetchSize`（通常500-5000）
4. 结果集类型必须为`FORWARD_ONLY`

# 10.自定义类型处理器
MyBatis-Plus 提供了强大的字段类型处理器(TypeHandler)功能，用于处理 Java 类型与数据库类型之间的转换。

### 一、JSON类型处理（内置处理器）
1. **实体类配置**
```java
@Data
@TableName(autoResultMap = true) // 必须开启
public class User {
    @TableField(typeHandler = JacksonTypeHandler.class)
    private Map<String, String> contact; // 自动转为JSON存储
}
```

2. **添加依赖**
```xml
<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.13.3</version>
</dependency>
```

3. **测试用例**
```java
// 插入测试
User user = new User();
Map<String, String> contact = new HashMap<>();
contact.put("phone", "13800138000");
contact.put("address", "Beijing");
user.setContact(contact);
userMapper.insert(user);

// 查询测试
User result = userMapper.selectById(user.getId());
System.out.println(result.getContact()); // 自动转为Map对象
```

### 二、注意事项
1. 必须添加`@TableName(autoResultMap = true)`注解
2. 查询时若字段为null，需检查：
   • 类型处理器是否注册成功
   • 数据库字段是否允许NULL
3. 内置JSON处理器需要对应JSON库依赖

### 三、最佳实践建议
1. 简单场景优先使用内置JSON处理器
2. 高频访问字段避免复杂类型转换
3. 为自定义处理器编写单元测试
4. 生产环境监控处理器执行耗时

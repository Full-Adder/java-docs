# 9.多数据源支持

MyBatis-Plus 提供了完善的多数据源支持方案，主要通过 dynamic-datasource-spring-boot-starter 扩展实现

### 一、基础配置方案
1. **依赖引入**（最新版本为 3.6.1）
```xml
<dependency>
  <groupId>com.baomidou</groupId>
  <artifactId>dynamic-datasource-spring-boot-starter</artifactId>
  <version>3.6.1</version>
</dependency>
```

2. **YAML配置示例**（支持主从分离）
```yaml
spring:
  datasource:
    dynamic:
      primary: master  # 默认数据源
      strict: false    # 是否严格匹配数据源
      datasource:
        master:
          url: jdbc:mysql://10.211.55.7:3306/mybatis-demo?useSSL=false&serverTimezone=UTC
          username: root
          password: root
        slave1: 
          url: jdbc:mysql://10.211.55.7:3306/mybatis-demo?useSSL=false&serverTimezone=UTC
          username: root
          password: 123456
```

### 二、核心使用方式
1. **注解切换数据源**（@DS）
```java
@Service
@DS("slave") // 类级别默认数据源
public class UserServiceImpl {
  
  @DS("slave_1") // 方法级别覆盖
  public List<User> queryFromSlave1() {
    return mapper.selectList(null);
  }
}
```

2. **编程式切换**（适用于动态场景）
```java
DynamicDataSourceContextHolder.push("slave2");
try {
  // 执行操作
} finally {
  DynamicDataSourceContextHolder.clear();
}
```

### 四、最佳实践建议
1. **连接池选择**：推荐配合 Druid 或 HikariCP 使用
2. **事务管理**：跨数据源操作需显式声明`@DSTransactional`
3. **性能优化**：为高频访问的从库配置连接池参数
4. **监控方案**：建议集成 Actuator 监控各数据源状态

### 五、常见问题解决
1. **注解不生效**：检查是否在 Spring 代理失效场景（如内部方法调用）
2. **事务异常**：确保`@Transactional`和`@DS`注解的加载顺序正确
3. **连接泄漏**：务必在编程式切换后执行`clear()`

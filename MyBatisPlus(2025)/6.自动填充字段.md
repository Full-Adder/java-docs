# 6.自动填充字段

MyBatis-Plus 提供了强大的自动填充功能，可以自动为创建时间、更新时间等公共字段赋值，极大简化了开发工作。以下是完整的实现方案：

## 一、基础配置步骤

### 1. 实体类字段标注

```java
@Data
public class User {
   
    @TableField(fill = FieldFill.INSERT) // 插入时自动填充
    private LocalDateTime createTime;
    
    @TableField(fill = FieldFill.INSERT_UPDATE) // 插入和更新时自动填充
    private LocalDateTime updateTime;
    
    @TableField(fill = FieldFill.INSERT) // 插入时填充创建人
    private Long createUser;
    
    @TableField(fill = FieldFill.INSERT_UPDATE) // 插入和更新时填充更新人
    private Long updateUser;
}
```

### 2. 实现 MetaObjectHandler

```java
@Component
public class MyMetaObjectHandler implements MetaObjectHandler {
    
    @Override
    public void insertFill(MetaObject metaObject) {
        this.strictInsertFill(metaObject, "createTime", LocalDateTime.class, LocalDateTime.now());
        this.strictInsertFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
        this.strictInsertFill(metaObject, "createUser", Long.class, getCurrentUserId());
    }

    @Override
    public void updateFill(MetaObject metaObject) {
        this.strictUpdateFill(metaObject, "updateTime", LocalDateTime.class, LocalDateTime.now());
        this.strictUpdateFill(metaObject, "updateUser", Long.class, getCurrentUserId());
        
//        this.setFieldValByName("updateTime", LocalDateTime.now(),metaObject);
//        this.setFieldValByName("updateUser", getCurrentUserId(),metaObject);
    }
    
    private Long getCurrentUserId() {
        // 获取当前用户ID逻辑
        return BaseContext.getCurrentId(); // 使用ThreadLocal实现
    }
}
```

## 二、高级功能实现

### 1. 动态获取用户信息

使用ThreadLocal存储当前用户信息：

```java
public class BaseContext {
    private static ThreadLocal<Long> threadLocal = new ThreadLocal<>();
    
    public static void setCurrentId(Long id) {
        threadLocal.set(id);
    }
    
    public static Long getCurrentId() {
        return threadLocal.get();
    }
}
```

在登录过滤器或拦截器中设置用户ID：

```java
// 登录成功后设置
BaseContext.setCurrentId(loginUser.getId());
```

### 2. 严格模式与非严格模式

• **strictInsertFill/strictUpdateFill**：严格模式，字段类型必须匹配
• **setFieldValByName**：非严格模式，更灵活但安全性较低

```java
// 严格模式（推荐）
this.strictInsertFill(metaObject, "createTime", LocalDateTime.class, LocalDateTime.now());

// 非严格模式
metaObject.setValue("createTime", new Date());
```

## 三、常见问题解决

### 1. 自动填充不生效

**可能原因**：
• 未添加`@Component`注解
• 字段名与注解中名称不一致
• 数据库字段允许NULL值
• 如果字段有值strict模式将不会覆盖填充

**解决方案**：
1. 检查处理器是否被Spring管理
2. 确认实体类字段名与数据库列名对应
3. 使用`strict`方法时确保类型匹配

### 2. 时间类型选择

推荐使用`LocalDateTime`而非`Date`：
```java
private LocalDateTime createTime; // JDK8+时间API
```

## 四、最佳实践建议

1. **公共字段统一处理**：将创建时间、更新时间等字段提取到基类
2. **使用ThreadLocal**：安全获取当前用户上下文
3. **生产环境日志**：在处理器中添加操作日志
4. **单元测试**：验证自动填充逻辑

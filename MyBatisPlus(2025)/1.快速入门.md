# 1.快速入门
## 一、MyBatis-Plus 简介

MyBatis-Plus（简称 MP）是一个 MyBatis 的增强工具，在 MyBatis 的基础上只做增强不做改变，为简化开发、提高效率而生。

### 核心特性
• **无侵入**：只做增强不做改变，引入它不会对现有工程产生影响
• **损耗小**：启动即会自动注入基本 CURD，性能基本无损耗
• **强大的 CRUD 操作**：内置通用 Mapper、通用 Service
• **支持 Lambda 形式调用**：方便的编写各类查询条件
• **内置代码生成器**：快速生成 Mapper、Model、Service、Controller 层代码
• **内置分页插件**：基于 MyBatis 物理分页，支持多种数据库

## 二、环境准备

### 1. 创建数据库和表

```sql
CREATE DATABASE `mybatis_plus_demo` DEFAULT CHARACTER SET utf8mb4;
USE `mybatis_plus_demo`;

CREATE TABLE `permission` (
  `id` varchar(500) CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci NOT NULL,
  `deleted` tinyint DEFAULT '0',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;

CREATE TABLE `test_generator` (
  `id` int DEFAULT NULL,
  `code` varchar(255) DEFAULT NULL,
  `model` varchar(255) DEFAULT NULL,
  `remark` varchar(255) DEFAULT NULL,
  `key` varchar(255) DEFAULT NULL,
  `status` varchar(255) DEFAULT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;

CREATE TABLE `user` (
  `id` int NOT NULL AUTO_INCREMENT,
  `name` varchar(255) DEFAULT NULL,
  `age` int DEFAULT NULL,
  `email` varchar(255) DEFAULT NULL,
  `status` varchar(255) DEFAULT NULL,
  `create_time` datetime DEFAULT NULL,
  `update_time` datetime DEFAULT NULL,
  `op_time` datetime DEFAULT NULL,
  `user_ext` varchar(255) DEFAULT NULL,
  `version` int DEFAULT NULL,
  `tenant_id` int DEFAULT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB AUTO_INCREMENT=1571093847 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

## 三、快速开始

### 1. 配置 application.yml

```yaml
spring:
  datasource:
    url: jdbc:mysql://10.211.55.7:3306/mybatis-demo?useSSL=false&serverTimezone=UTC
    username: root
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver
mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
```

### 2. 创建实体类

```java
@Data
@TableName(value = "user", autoResultMap = true)
public class User {
    @TableId(type = IdType.AUTO)
    private Integer id;
    private String name;
    private Integer age;
    private String email;
}
```

### 3. 创建 Mapper 接口

```java
@Mapper
public interface UserMapper extends BaseMapper<User> {
}
```

### 4. 添加 @MapperScan 注解

```java
@SpringBootApplication
@MapperScan("com.example.mybatisplusdemo.mapper")
public class MybatisPlusDemoApplication {
	public static void main(String[] args) {
		SpringApplication.run(MybatisPlusDemoApplication.class, args);
	}
}
```

## 四、基本 CRUD 操作

### 1. 插入操作

```java
    @Test
    public void testInsert() {
        User user = new User();
        user.setAge(10);
        user.setName("example");
        user.setEmail("example@qq.com");
        userMapper.insert(user);
    }
```

### 2. 查询操作

```java
// 根据ID查询
@Test
    public void testSelectById() {
        User user = userMapper.selectById(1570893825);
        System.out.println(user);
    }

// 查询所有
@Test
    public void testSelect() {
        List<User> users = userMapper.selectList(null);
        users.forEach(System.out::println);
    }
```

### 3. 更新操作

```java
@Test
    public void testUpdate() {
        User user = userMapper.selectById(1570893826);
        user.setName("example 测试更新");
        userMapper.updateById(user);
    }
```

### 4. 删除操作

```java
@Test
    public void testDelete() {
        userMapper.deleteById(1570893825);
    }
```

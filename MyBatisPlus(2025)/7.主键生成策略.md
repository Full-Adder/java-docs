# 7.主键生成策略
MyBatis-Plus 提供了多种主键生成策略，以下是完整的策略说明和使用指南：

### 一、主键策略类型
MyBatis-Plus 支持以下 5 种主键生成策略（通过 `IdType` 枚举定义）：

| 策略值       | 描述                                                                 |
|--------------|----------------------------------------------------------------------|
| AUTO         | 数据库 ID 自增（需数据库支持自增）                                   |
| NONE         | 无状态（跟随全局配置，默认全局为 ASSIGN_ID）                         |
| INPUT        | 需手动设置主键值（或通过 `IKeyGenerator` 接口实现）                  |
| ASSIGN_ID    | 自动分配 ID（默认雪花算法，支持 Long/String 类型）                   |
| ASSIGN_UUID  | 自动分配 UUID（String 类型）                                         |

### 二、配置方式

#### 1. 局部注解配置（优先级最高）
```java
@Data
public class Permission {
    @TableId(value = "id", type = IdType.AUTO) // 数据库自增
    private Long id;
    
    @TableId(type = IdType.ASSIGN_ID) // 雪花算法（默认）
    private String orderId;
}
```

#### 2. 全局配置（优先级中）
```yaml
mybatis-plus:
  global-config:
    db-config:
      id-type: assign_id # 全局默认策略
```

#### 3. 默认策略（优先级最低）
未配置时默认使用 `ASSIGN_ID`（雪花算法）

### 三、策略详解

#### 1. 雪花算法（ASSIGN_ID）
• 默认实现类：`DefaultIdentifierGenerator`
• 特点：
  • 64位ID（1符号位 + 41时间戳 + 10机器ID + 12序列号）
  • 支持分布式系统唯一ID
  • 性能高（每秒可生成400万+ID）

#### 2. 数据库自增（AUTO）
使用要求：
```sql
CREATE TABLE Permission (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    ...
)
```
实体类配置：
```java
@TableId(type = IdType.AUTO)
private Long id;
```

#### 3. UUID策略（ASSIGN_UUID）
```java
@TableId(type = IdType.ASSIGN_UUID)
private String uuid;
```

### 四、扩展自定义策略
实现 `IdentifierGenerator` 接口：
```java
@Component
public class CustomIdGenerator implements IdentifierGenerator {
    @Override
    public Long nextId(Object entity) {
        // 自定义ID生成逻辑
         return IdWorker.getId();
    }
}
```

### 五、最佳实践建议
1. 单机项目：推荐 `AUTO`（简单高效）
2. 分布式系统：推荐 `ASSIGN_ID`（默认雪花算法）
3. 需要字符串主键：使用 `ASSIGN_UUID`
4. 特殊业务规则：实现 `IKeyGenerator` 接口

> 注意：不同策略的优先级为 **注解配置 > 全局配置 > 默认配置**

# 12.代码生成

#### **一、准备工作**
1. **添加依赖**  
   在项目的 `pom.xml` 文件中添加 MyBatisPlus 代码生成器的依赖：
   ```xml
   <dependency>
       <groupId>com.baomidou</groupId>
       <artifactId>mybatis-plus-generator</artifactId>
       <version>3.5.1</version>
   </dependency>
   ```

2. **配置数据库连接**  
```yaml
spring:
  datasource:
    url: jdbc:mysql://10.211.55.7:3306/mybatis_plus_demo?useSSL=false&serverTimezone=UTC
    username: root
    password: root
    driver-class-name: com.mysql.cj.jdbc.Driver
mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
```
#### **二、创建代码生成器类**
1. **创建 `AutoCodeGenerator` 类**  
   在项目中创建一个类，例如 `AutoCodeGenerator`，并导入相关依赖：
   ```java
   import com.baomidou.mybatisplus.annotation.IdType;
   import com.baomidou.mybatisplus.generator.FastAutoGenerator;
   import com.baomidou.mybatisplus.generator.config.DataSourceConfig;
   import com.baomidou.mybatisplus.generator.config.OutputFile;
   import com.baomidou.mybatisplus.generator.config.rules.NamingStrategy;
   import com.baomidou.mybatisplus.generator.engine.FreemarkerTemplateEngine;
   import org.springframework.core.io.ClassPathResource;
   import org.springframework.core.io.Resource;
   import java.io.IOException;
   import java.util.HashMap;
   import java.util.Map;
   ```

2. **配置代码生成器**  
   在 `AutoCodeGenerator` 类中配置代码生成器：
   ```java
   public class AutoCodeGenerator {
       public static void main(String[] args) throws IOException {
           // 读取数据库配置
           String driverClassName = "com.mysql.cj.jdbc.Driver";
           String username = "root";
           String password = "root";
           String url = "jdbc:mysql://10.211.55.7:3306/mybatis_plus_demo?useSSL=false&serverTimezone=UTC";
           String author = "编程学习";
           String tableName = "test_code_generator"; // 指定表名，多个表用逗号分隔

           // 项目路径
           String projectPath = System.getProperty("user.dir");

           // 创建代码生成器
           FastAutoGenerator.create(new DataSourceConfig.Builder(url, username, password))
                   .globalConfig(builder -> builder
                           .author(author)
                           .outputDir(projectPath + "/src/main/java")
                           .dateType(com.baomidou.mybatisplus.generator.config.rules.DateType.ONLY_DATE)
                   )
                   .packageConfig(builder -> builder
                           .parent("com.example")
                           .moduleName("demo")
                           .entity("entity")
                           .service("service")
                           .serviceImpl("service.impl")
                           .mapper("mapper")
                           .controller("controller")
                   )
                   .strategyConfig(builder -> builder
                           .addInclude(tableName.split(","))
                           .entityBuilder()
                           .idType(IdType.AUTO)
                           .naming(NamingStrategy.underline_to_camel)
                           .columnNaming(NamingStrategy.underline_to_camel)
                           .RestControllerStyle()
                   )
                   .templateEngine(new FreemarkerTemplateEngine())
                   .execute();
       }
   }
   ```

#### **三、运行代码生成器**
1. **运行主方法**  
   执行 `AutoCodeGenerator` 类的 `main` 方法，代码生成器会根据配置生成以下文件：
   - 实体类（Entity）
   - Mapper 接口
   - XML 映射文件
   - Service 接口
   - Service 实现类
   - Controller 层

#### **四、IDEA 插件（可选）**
1. **安装 MyBatisPlus 插件**  
   在 IntelliJ IDEA 的 `Plugins` 中搜索并安装 `MyBatisPlus` 插件，重启 IDEA。

2. **使用插件生成代码**  
   - 配置数据库连接信息。
   - 选择需要生成代码的表。
   - 配置代码生成选项（如包名、作者信息等）。
   - 点击生成按钮，插件会自动生成代码。

#### **五、注意事项**
- **表名和字段命名**：建议使用下划线命名，代码生成器会自动转换为驼峰命名。
- **模板引擎**：可以自定义模板，例如使用 `Freemarker` 或 `Velocity`。
- **代码覆盖**：如果需要覆盖已有代码，可以在配置中设置 `fileOverride` 为 `true`。

通过以上步骤，您可以快速生成符合 MyBatisPlus 风格的代码，大幅提高开发效率！

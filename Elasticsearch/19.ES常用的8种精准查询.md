# 19.ES常用的8种精准查询
精准查询指的是文本不需要通过文本分析直接存入到ES，查询时也不需要对关键词进行分词处理。
## 数据准备
### 设置mapping
```
PUT example_data01
{
  "mappings": {
    "properties": {
      "address":{
        "type": "text",
        "index_prefixes":{
          "min_chars":1,
          "max_chars":5
        }
      },
      "age":{
        "type": "integer"
      },
      "stuNo":{
        "type": "keyword"
      },
      "stuName":{
        "type": "text",
        "fields": {
          "keyword":{
            "type":"keyword",
            "ignore_above":256
          }
        }
      }
    }
  }
}
```
### 添加数据
```
PUT example_data01/_doc/1
{
  "stuName":"赵云",
  "stuNo":"20230987",
  "age":1000,
  "address":"china anhui hefei"
}
PUT example_data01/_doc/2
{
  "stuName":"张飞",
  "stuNo":"20230988",
  "age":1008,
  "address":"china jiangsu suzhou"
}

PUT example_data01/_doc/3
{
  "stuName":"赵云云",
  "stuNo":"20230989",
  "age":997,
  "address":"china zhejiang hangzhou"
}

PUT example_data01/_doc/4
{
  "stuName":"刘备",
  "stuNo":"20230989",
  "age":1010,
  "flag":"大哥",
  "address":"china guangdong shenzhen"
}
```
## 查询用法
### term 查询
用来精准匹配某个字段的全部文本，如果字段类型设置为text，将有可能匹配不上
```
POST example_data01/_search
{
  "query": {
    "term": {
      "stuName.keyword": {
        "value": "张飞"
      }
    }
  }
}
```
```

这个用来匹配某个字段多个值
```

### 范围查询
支持数值的范围查询，还有时间范围，时间注意有时区的限制，默认为UTC时区，一般建议存时间戳
```
POST example_data01/_search
{
  "query": {
    "range": {
      "age": {
        "gte": 995,
        "lte": 1005
      }
    }
  }
}
```

这个一般用来判断某个字段为空或者没有这个字段

  }
}

# 18.如何在索引中使用自定义分析器
## 分析
经过前面的学习，我们已经掌握了分析器是由过滤器、分词器和分词过滤器组成，所以这节课我自定义一个分析器，然后在索引中去使用
假设我们要创建一个名为"custom_analyzer"的分析器，它使用以下配置：
分词器（Tokenizer）：使用Whitespace Tokenizer，按空格对文本进行简单的切分。
分词过滤器（Token Filter）：使用Lowercase Token Filter将文本转换为小写，并且使用Stopword Token Filter去除停用词。
过滤器（Filter）：使用html_strip处理html标签
## 代码部分
### 自定义分析器
```
PUT /example_analyze
{
  "settings": {
    "analysis": {
      "analyzer": {
        "custom_analyzer": {
          "type": "custom",
          "char_filter":["html_strip"],
          "tokenizer": "whitespace",
          "filter": ["lowercase", "my_stopwords"]
        }
      },
      "filter": {
        "my_stopwords": {
          "type": "stop",
          "stopwords": ["a", "an", "the", "and", "is", "are", "in", "on", "of"]
        }
      }
    }
  }
}
```
### 使用自定义分析器分析文本
```
POST /example_analyze/_analyze
{
"text": ["The quick brown fox jumps over the lazy <span>dog</span>"],
"analyzer": "custom_analyzer"
}
```

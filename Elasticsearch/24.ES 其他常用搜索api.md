# 24.ES 其他常用搜索api
## 筛选搜索结果
如果你的索引字段非常多，在一次查询中，你只用到其中几个字段，并不希望返回全部字段，那么你可以通过以下几种方式实现
### _source
```
POST example_page/_search
{
  "_source": ["stuNo"]
}
```
### includes or excludes
```
POST example_page/_search
{
  "_source": {
    "excludes": ["userName","manager"]
  }
}
```
## 高亮搜索结果
会将命中的分词前后包裹标签，并且结果中会添加一个字段用来展示，不影响原始数据
```
POST example_data02/_search
{
  "query": {
    "match": {
      "good_name": "笔记本"
    }
  },
  "highlight": {
    "pre_tags": "<span>",
    "post_tags": "</span>",
    "fields": {"good_name": {}}
  }
}
```

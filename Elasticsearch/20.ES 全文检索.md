## 查询
### 匹配查询
#### 用途
用于在指定字段中搜索包含指定文本的文档。它会对搜索词进行分词，然后查找包含至少一个匹配词的文档
#### 用法
```
POST example_data02/_search
{
  "query": {
    "match": {
      "good_name": "英特尔酷"
    }
  }
}
```
### 短语搜索
#### 用途
查询要求文本与搜索词以相同的顺序和相邻的方式出现
#### 用法
```
POST example_data02/_search
{
  "query": {
    "match_phrase": {
      "good_name": {
        "query": "联想 小新",
        "slop": 5
      }
    }
  }
}
```
### 多字段查询
#### 用途
适用于同一个关键词需要在多个字段中搜索
#### 用法
```
POST example_data02/_search
{
  "query": {
    "multi_match": {
      "query": "联想 杜甫",
      "fields": ["good_name","buyer"],
      "operator": "or"
    }
  }
}
```
### 查询字符串搜索
#### 用途
query_string 查询是一种强大的查询类型，它允许您使用类似于查询字符串的语法来进行全文检索。这种查询类型非常灵活，能够满足各种搜索需求。

* 搜索字段：您可以指定要在哪些字段中搜索。例如，搜索多个字段：field1:search_text OR field2:search_text。

* 逻辑运算符：支持 AND、OR、NOT 运算符，分别表示与、或、非关系。

* 通配符：支持使用 * 通配符匹配任意字符，例如 app* 可以匹配 "apple"、"application" 等。

* 模糊搜索：使用 ~ 运算符进行模糊搜索，例如 quick~ 可以匹配 "quick"、"quack" 等。

* 范围搜索：使用 {} 来表示范围搜索，例如 price:[100 TO 500] 可以匹配价格在 100 到 5*00 之间的文档。

* 分组：使用 () 进行分组搜索，例如 (word1 OR word2) AND category:electronics。

* 转义字符：使用 \ 进行特殊字符的转义，例如 quick\* 可以匹配 "quick*" 而不是应用通配符。

#### 用法
```
POST example_data02/_search
{
  "query": {
    "query_string": {
      "query": "杜甫 OR 李白"
    }
  }
}
```

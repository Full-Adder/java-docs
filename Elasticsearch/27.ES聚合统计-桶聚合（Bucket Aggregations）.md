# 27.ES聚合统计-桶聚合（Bucket Aggregations）
## Terms Aggregation
select tag,count(1) from example_agg group by tag
```
POST example_agg/_search
{
  "size": 0, 
  "aggs": {
    "groupBy_tag":{
      "terms": {
        "field": "tag.keyword"
      }
    }
  }
}
```
## Range Aggregation(范围聚集)
我想统计指定年龄区间，内有多少人
0-1000,1000-1300,1300-
```
POST example_agg/_search
{
  "size": 0, 
  "aggs": {
    "range_age":{
      "range": {
        "field": "age",
        
        "ranges": [
          {
            "to": 1000
          },
          {
            "from":1000,
            "to": 1300
          },
          {
            "from": 1300
          }
        ]
      }
    }
  }
}
```
```
  "aggregations": {
    "range_age": {
      "buckets": [
        {
          "key": "*-1000.0",
          "to": 1000,
          "doc_count": 1
        },
        {
          "key": "1000.0-1300.0",
          "from": 1000,
          "to": 1300,
          "doc_count": 1
        },
        {
          "key": "1300.0-*",
          "from": 1300,
          "doc_count": 3
        }
      ]
    }
  }
```

## Histogram Aggregation
如果你想按照固定间隔统计数据：如 0-10 10-20 20-30，那你可以使用这个
```
POST example_agg/_search
{
  "size": 0, 
  "aggs": {
    "age_histogram":{
      "histogram": {
        "field": "age",
        "interval": 50
      }
    }
  }
}
```

950-1000：1
1250-1300:1

## Date Histogram Aggregation
如果你想按照日期间隔进行统计，那么你可以使用这个
```
POST example_agg_date/_search
{
  "size": 0, 
  "aggs": {
    "order_time_date_histogram": {
     "date_histogram": {
       "field": "order_time",
       "fixed_interval": "1d"
     }
    }
  }
}
```

```
  "aggregations": {
    "order_time_date_histogram": {
      "buckets": [
        {
          "key_as_string": "2023-08-03 00:00:00",
          "key": 1691020800000,
          "doc_count": 2
        },
        {
          "key_as_string": "2023-08-04 00:00:00",
          "key": 1691107200000,
          "doc_count": 2
        }
      ]
    }
  }
```
## 聚合前过滤数据
如果你想在聚合数据前过滤一些数据，但是不想影响搜索结果，那么你可以使用，
过滤tag=【A,B】,书写时请注意结构
```
POST example_agg/_search
{
  "query": {
    "match_all": {}
  },
  "aggs": {
    "my_filter": {
      "filter": {
        "terms": {
          "tag.keyword": ["A","B"]
        }
      },
      "aggs": {
        "groupby_tag": {
          "terms": {
            "field": "tag.keyword"
          }
        }
      }
    }
  }
}   
```

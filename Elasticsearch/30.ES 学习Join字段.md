# 30.ES 学习Join字段
"join" 数据类型是一种特殊的字段，它在同一个索引的文档之间创建父/子关系。"relations" 部分定义了文档内可能的一组关系，每个关系都由父名称和子名称组成。
## Join和Nested区别
"join" 和 "nested" 都是用于处理文档之间的关系，但它们的工作方式和适用场景有所不同。
### Nested（嵌套）：
#### 定义
"nested" 数据类型允许您在一个文档中嵌套另一个文档，从而创建一个层次结构。每个嵌套文档被视为单独的对象，可以通过 Nested 查询来检索。每个嵌套文档都被存储在独立的 Lucene 文档中，但它们仍然与其父文档相关联。
#### 适用场景：
当父文档和嵌套文档具有明确的父子关系时，如用户和订单，可以在用户文档中嵌套订单文档。
当您需要同时查询父文档和其嵌套的子文档时，使用 Nested 查询可以很方便。
### Join（联接）：

#### 定义
"join" 数据类型允许在同一个索引中创建父/子关系。它类似于 SQL 中的联接，可以在同一索引中的文档之间创建关系。"join" 字段允许您将文档标记为父文档或子文档，并指定哪些字段用作父子关系的连接字段。这可以用于构建多层次的关系。

#### 适用场景：

当您需要在同一索引中创建父子文档的关系时，例如在索引中存储组织结构或层次化数据。
当您需要在查询中针对父文档和子文档之间的关系进行复杂查询时，例如检索所有属于特定父文档的子文档。

总结起来，"nested" 适用于在单个文档中嵌套相关数据，而 "join" 适用于在同一索引中的文档之间创建父子关系，允许您进行更复杂的层次化查询。您应根据您的数据模型和查询需求来选择适当的方法。
## Join 字段mapping设置
```
PUT example_demo_join
{
  "mappings": {
    "properties": {
      "order_no": {
        "type": "keyword"
      },
      "order_time": {
        "type": "date",
        "format": [
          "yyyy-MM-dd HH:mm:ss"
        ]
      },
      "good_name": {
        "type": "text",
        "fields": {
          "keyword": {
            "type": "keyword"
          }
        }
      },
      "price": {
        "type": "float"
      },
      "count": {
        "type": "integer"
      },
      "goods_join_order": {
        "type": "join",
        "relations": {
          "order": "goods"
        }
      }
    }
  }
}
```

## 数据搜索
### 以父搜子
以父级为搜索条件，查询子数据
```
POST example_demo_join/_search
{
  "query": {
    "has_parent": {
      "parent_type": "order",
      "query": {
        "term": {
          "buyer": {
            "value": "neil"
          }
        }
      }
    }
  }
}
```
如果想让父文档一起返回，则加上参数“inner_hits”:{}
```
POST example_demo_join/_search
{
  "query": {
    "parent_id":{
      "type":"goods",
      "id":"10003"
    }
  }
}
```
### 以子搜父
根据子数据条件搜索父数据
```
POST example_demo_join/_search
{
  "query": {
    "has_child": {
      "type": "goods",
      "query": {
        "term": {
          "good_name.keyword": {
            "value": "苹果手机"
          }
        }
      },
      "inner_hits": {}
    }
  }
}
```
## Join 聚合
```

{
  "aggs": {
    "order_buyer": {
      "terms": {
        "field": "buyer.keyword"
      },
      "aggs": {
        "good_datas": {
          "children": {
            "type": "goods"
          },
          "aggs": {
            "agg_good_name": {
              "terms": {
                "field": "good_name.keyword"
              }
            }
          }
        }
      }
    }
  }
}
```

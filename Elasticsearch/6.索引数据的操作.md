# 6.索引数据的操作

## 基本操作
### 创建索引结构
```
PUT example_crud
{
  "mappings": {
    "properties": {
      "age":{
        "type": "integer"
      },
      "stu_no":{
        "type": "keyword"
      },
      "score":{
        "type": "float"
      },
      "birth":{
        "type":"date"
      }
  }
  }
}
```
### 添加数据
```
POST example_crud/_doc/1
{
  "age":10,
  "stu_no":"1301098762",
  "score":90.8,
  "birth":"2023-07-01"
}
```
### 更新数据
```
PUT example_crud/_doc/1
{
  "age":15,
  "stu_no":"1301098762"
}
```
### 更新指定字段
```
POST example_crud/_update/1
{
  "doc": {
    "age": 18,
    "stu_no": "1301098762"
  }
}
```
### 查询数据
```
GET example_crud/_doc/1
```
### 删除数据
```
DELETE example_crud/_doc/1
```
## 批量提交
每次查询、删除、更新等操作，都会与ES建立一次连接，这会导致大量的请求打在ES服务器上面，从而间接导致数据索引变慢，那么ES是不是可以搞一个批量请求提交，多个操作都在一个请求中完成？答案当然是可以的啦，那我们看下怎么操作
```
POST example_bulk/_bulk
{"index":{"_id":"1"}}
{"id":1,"name":"编程学习"}
{"update":{"_id":"1"}}
{"doc":{"id":1,"name":"编程学习3"}}
```
执行次请求后，做一次查询，可以看到name为“编程学习3”

```
POST example_bulk/_bulk
{"index":{"_id":"1"}}
{"id":1,"name":"编程学习"}
{"update":{"_id":"1"}}
{"doc":{"id":1,"name":"编程学习3"}}
{"delete":{"_id":"1"}}
```
执行完这个，数据将被删除
## 索引重建
在产线环境，我们都是使用静态mapping，用了一段时间后，业务需求有变动，我们需要更新字段类型或者数据量太大，我们需要扩展分片数量，但是经过前面的学习，大家都知道，这些都是无法修改的，所以我们的解决办法通常是重建索引，然后将老数据给merge过去，那我们来看下ES如何实现这个功能
* 创建旧索引
```
PUT example_reindex_old/_doc/1
{
  "name":"编程学习",
  "count":"10"
}
```
* 查看旧索引信息
    * settings:{分片1个，副本1个}
    * mappings:{name:text,count:text}
```
GET example_reindex_old

{
  "example_reindex_old": {

    "mappings": {
      "properties": {
        "count": {
          "type": "text",
          "fields": {
            "keyword": {
              "type": "keyword",
              "ignore_above": 256
            }
          }
        },
        "name": {
          "type": "text",
          "fields": {
            "keyword": {
              "type": "keyword",
              "ignore_above": 256
            }
          }
        }
      }

      "index": {

创建新索引，指定分片2个，副本2个，name：keyword,count:long
### 创建新索引
```
PUT example_reindex_new
{
  "mappings": {
    "properties": {
      "name": {
        "type": "keyword"
      },
      "count": {
        "type": "long"
      }
    }
  },
  "settings": {
    "number_of_shards": 3,
    "number_of_replicas": 2
  }
}
```
看下配置
```

### 执行索引重建
* source：旧索引信息
* dest：目标索引信息
```
POST _reindex
{
  "source": {"index": "example_reindex_old"},
  "dest": {"index": "example_reindex_new"}
}
```

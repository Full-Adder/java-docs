# 16.安装第三方分词器:IK 中文分词器

## 安装
安装第三方分词器，只需要两步
* 安装插件
```
docker exec -it es-es01-1 /bin/bash
cd /usr/share/elasticsearch
# 如果大家安装的版本不是8.8.2,只需要换成对应版本即可
./bin/elasticsearch-plugin install https://github.com/medcl/elasticsearch-analysis-ik/releases/download/v8.8.2/elasticsearch-analysis-ik-8.8.2.zip
```
* 重启es服务
```
docker restart es-es01-1
```
## 使用
经过上面的步骤，我们已经成功安装IK分词器，接下来我门在dev tools上面演示如何去使用
IK 有两种常用的分析器：ik_max_word和ik_smart，我们分别看下他们有什么区别？
### ik_max_word 分析器
```
POST _analyze
{
  "analyzer": "ik_max_word",
  "text": "你好，上海自来水来自海上"
}
```

### ik_smart分析器
```
POST _analyze
{
  "analyzer": "ik_smart",
  "text": "你好，上海自来水来自海上"
}
```
分词结果

```
{
  "tokens": [
    {
      "token": "你好",
      "start_offset": 0,
      "end_offset": 2,
      "type": "CN_WORD",
      "position": 0
    },
    {
      "token": "上海",
      "start_offset": 3,
      "end_offset": 5,
      "type": "CN_WORD",
      "position": 1
    },
    {
      "token": "自来水",
      "start_offset": 5,
      "end_offset": 8,
      "type": "CN_WORD",
      "position": 2
    },
    {
      "token": "来自",
      "start_offset": 8,
      "end_offset": 10,
      "type": "CN_WORD",
      "position": 3
    },
    {
      "token": "海上",
      "start_offset": 10,
      "end_offset": 12,
      "type": "CN_WORD",
      "position": 4
    }
  ]
}
```
通过比较可以看出，IK_MAX_WORD 分出来的词语更细致，但是IK_SMART也能很精准的进行分词，所以在使用中，一般在进行文本分析时会使用IK_MAX_WORD，分出更多词语，搜索时使用IK_SMART分词，能更准确的搜索我们想要的。

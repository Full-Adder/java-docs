## 平均值
```
POST example_agg/_search
{
  "size": 0, 
  "aggs": {
    "age_avg": {
      "avg": {
        "field": "age"
      }
    }
  }
}
```
```
"aggregations": {
    "age_avg": {
      "value": 1240.6
    }
  }
```

## 统计字段中不同值的数量
当数据不准确时，可以通过调整"precision_threshold"，来控制精确度
```
POST example_agg/_search
{
  "size": 0, 
  "aggs": {
    "tag_cardinality": {
      "cardinality": {
        "precision_threshold": 100,
        "field": "tag.keyword"
      }
    }
  }
}
```
```
"aggregations": {
    "tag_cardinality": {
      "value": 3
    }
  }
```

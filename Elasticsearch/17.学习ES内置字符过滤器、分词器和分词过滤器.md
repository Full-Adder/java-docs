# 17.学习ES内置字符过滤器、分词器和分词过滤器
这节课我们开始学习ES提供的几种默认字符过滤器、分词器和分词过滤器的使用
## 字符过滤器
在数据索引和搜索的过程中，字符过滤器用于预处理文本数据，将输入文本中的字符进行转换、删除或替换，以便更好地进行搜索和分析。
字符过滤器在文本处理管道中的位置位于分词器之前，用于处理原始文本数据。当文本被传递给分词器之前，字符过滤器可以执行一系列操作，如去除HTML标签、转换大小写、删除特定字符、替换特定字符等。
### HTML strip字符过滤器
#### 用途
去除HTML标签及解析转义字符串
#### 用法
```
POST _analyze
{
  "char_filter": ["html_strip"],
  "filter": [],
  "text": [
    "<b>hello</b>&nbsp;我是示例用户聊<span>编程</span>"
    ]
}
```
```
{
  "tokens": [
    {
      "token": "hello 我是编程学习",
      "start_offset": 3,
      "end_offset": 38,
      "type": "word",
      "position": 0
    }
  ]
}
```
将HTML标签br和span移除，并解析了“&nbsp”为空格
### 映射字符过滤器
#### 用途
根据指定的映射表，替换文本中的字符
#### 用法
```
POST _analyze
{
  "char_filter": [
    {
      "type": "mapping",
      "mappings": [
        "示例用户 => 示例作者"
      ]
    }
  ],
  "filter": [],
  "text": [
    "<b>hello</b>&nbsp;我是示例用户聊<span>编程</span>"
  ]
}
```
```
{
  "tokens": [
    {
      "token": "<b>hello</b>&nbsp;我是示例作者聊<span>编程</span>",
      "start_offset": 0,
      "end_offset": 38,
      "type": "word",
      "position": 0
    }
  ]
}
```
将“示例用户”替换成了 “示例作者”
### 正则替换字符过滤器
#### 用途 
使用正则表达式来替换文本中的字符
#### 用法
```
POST _analyze
{
  "char_filter": [
    {
      "type": "pattern_replace",
      "pattern":"\\d+",
      "replacement":"！！！"
    }
  ],
  "filter": [],
  "text": [
    "<b>hello</b>&nbsp;我是2示例用户112聊<span>编442程</span>"
  ]
}
```
```
{
  "tokens": [
    {
      "token": "<b>hello</b>&nbsp;我是！！！示例用户！！！聊<span>编！！！程</span>",
      "start_offset": 0,
      "end_offset": 45,
      "type": "word",
      "position": 0
    }
  ]
}
```
将数字替换成“！！！”
## 分词器
分词器用于将输入的文本数据分割成独立的词（或称为词条，term），以便更好地进行索引、搜索和分析。
### Standard Tokenizer（标准分词器）
根据非字母字符（如空格、标点符号等）进行分词，删除大多数标点符号，它适用于大多数一般的全文搜索场景。
```
POST _analyze
{
  "tokenizer": "standard", 
  "text": [
    "hello. my name is 编程学习！"
  ]
}
```
```
{
  "tokens": [
    {
      "token": "hello",
      "start_offset": 0,
      "end_offset": 5,
      "type": "<ALPHANUM>",
      "position": 0
    },
    {
      "token": "my",
      "start_offset": 7,
      "end_offset": 9,
      "type": "<ALPHANUM>",
      "position": 1
    },
    {
      "token": "name",
      "start_offset": 10,
      "end_offset": 14,
      "type": "<ALPHANUM>",
      "position": 2
    },
    {
      "token": "is",

      "end_offset": 17,

    {
      "token": "乐",

### Whitespace Tokenizer（空格分词器）
这个分词器根据空格字符进行分词，不处理标点符号。适用于特定的文本分析场景。
```
POST _analyze
{
  "tokenizer": "whitespace", 
  "text": [
    "hello. my name is 编程学习！"
  ]
}
```
```
{
  "tokens": [
    {
      "token": "hello.",
      "start_offset": 0,
      "end_offset": 6,
      "type": "word",
      "position": 0
    },
    {
      "token": "my",
      "start_offset": 7,
      "end_offset": 9,
      "type": "word",
      "position": 1
    },
    {
      "token": "name",

      "end_offset": 14,
      "type": "word",
      "position": 2
    },
    {
      "token": "is",

    {
      "token": "编程学习！",
      "start_offset": 18,
      "end_offset": 24,
      "type": "word",
      "position": 4
    }
  ]
}
```
### Keyword Tokenizer（关键字分词器）
这个分词器将整个输入视为单个词条，不进行分词。适用于需要精确匹配整个字段的情况。
```
POST _analyze
{
  "tokenizer": "keyword", 
  "text": [
    "hello. my name is 编程学习！"
  ]
}
```
```
{
  "tokens": [
    {
      "token": "hello. my name is 编程学习！",
      "start_offset": 0,
      "end_offset": 24,
      "type": "word",
      "position": 0
    }
  ]
}
```
### Letter Tokenizer（字母分词器）

## 分词过滤器
### Stopword Filter
#### 用途
去除停用词，例如"a", "an", "the"等常见但没有实际意义的词汇，以减少索引大小和提高查询效率。
#### 用法
```
POST _analyze
{
"tokenizer": "standard", 
"filter": ["stop"], 
  "text": [
    "the quick brown fox jumps over the lazy dog."
  ]
}
```
```
